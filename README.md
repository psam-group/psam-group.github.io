# PSAM-Group

Official website source for **PSAM-Group — Plant Stress Analysis & Modeling**.

Institute of Plant Physiology and Genetics, Bulgarian Academy of Sciences, Sofia, Bulgaria.

## Research

- Drought stress physiology in plants
- Nutrient deficiency analysis
- Mathematical modeling of plant stress
- Artificial intelligence and predictive analytics

## Website

GitHub Pages: [https://psam-group.github.io/](https://psam-group.github.io/)

The website is bilingual (English/Bulgarian) and is built with React, TypeScript and Vite.

## Local development

```bash
npm ci
npm run build:pages
```
